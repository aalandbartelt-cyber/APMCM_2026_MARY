## 1. 三问分别要求什么

**P1 是只凭组成预测非负违反度的监督学习问题，同时服务于低违反度搜索。** 输入是有方向的 A 位、B 位与 X 族；训练标签由五个平方铰链惩罚相加得到。02 用于训练；03 用于模型选择；04 是最终未标注测试。DFT 与几何列可以作为训练阶段的预测目标或辅助监督，不能作为部署时必须提供的输入。`id`、文件顺序、哈希切分、已知正例宿主信息不应成为化学特征。

设组成为 c=(A,B,X)，

\[
V(c)=\sum_{d\in\{e_{form}-0.21,\,1.4-E_g,\,E_g-3.1,\,5.73-VBM,\,CBM-4.50\}}
\left[\max(0,d)/0.5\right]^2.
\]

目标既包括数值预测，也包括候选池最低端的排序。题目未公开指定 P1 是按 RMSE、tau、命中率或综合指标计分；任何这些指标都只能标作队内验证口径，不能说成官方评分公式。

**P2 是固定 X=NO2 的单个候选选择。** 在合法池中从 52 个 A 和 52 个 B 各选一个，使同一套代理模型的预测违反度最小，并按题目要求用 Kaiwu SDK 建模和求解 QUBO。02+03 可用于该阶段训练。07 是完整 2704 态，11 是其与未标注测试的交集 529 态。选用哪条池口径必须写清楚，不能把两个池的最优值混比。求解器是否找到代理最优与所选组成是否真实满足物理条件是两件事。

**P3 是在 O3、NO2、FO2 中再选择一个 X 的单个候选选择。** 完整池 08 含 8112 态，盲池 12 含 1587 态。仍以 02+03 训练的代理目标为准，需 QUBO 和 Kaiwu 求解。题目前言明确要求讨论硬件系数限制和逐项成本，但没有给出固定的精度适配方案、求解器优势保证或评分权重。本阶段只明确需求，不实施 P2/P3。

## 3. 必须明示的题面歧义

1. **15 与 19 同时出现在官方英文原件。** 第 1/2 页和 README 写 V=0 共 19 条，第 3 页严格不等式段落写 15 条。平方铰链本身在阈值等号处也为零，不能在数学上把 V=0 与全部严格不等式混为一谈。以公式与公开 V 列为预测目标；严格物理通过另设口径，不能凭想象解释四条差异，也不检索隐藏真值来核对。
2. **开头称预定义 surrogate，P1 又要求自己训练。** 附件中没有现成的可执行代理模型；实际工作按 P1 构建并冻结代理，再交给后续问。已有 V 是标签，不是现成代理。
3. **候选池不是同一个任务规模。** 完整池允许含已见组成，盲池只允许未见组；最终候选输出要标识 pool_id 与训练口径。对非矩形盲池，后续的编码还需保证不会生成池外组合。
4. **没有公开预测文件规格。** 题面说 04 用于最终测试，但当前官方材料未给单独预测文件的列名、上传位置或具体评分程序。登记待核，不能自行宣称赛氪支持某种 CSV 上传。
5. **A=B 合法且 A/B 位有方向。** 保留题目全集，不用全网格“没有正例”的公告当作删除特征或改变可行域的理由；是否可交换不能假定。

## 4. 评价与真正难点

官方评阅是解读、假设、建模思路、模型有效、稳定性、优缺点与结论、摘要七项。对于本题，还需把代理误差、编码误差、精度变换误差、求解误差和费用分别交代，不能将它们合成“量子效果”。

训练和验证没有严格正例，普通二分类的正类概率不能从这两个文件直接识别；它也不是典型的“有标注正例+未标注混合”的 PU 学习设定。需要利用连续物理/违反度监督提出可检验方案，而非制造零标签样本或报告没有真实正例支持的召回率。

切分按有向元素对隔离，同一元素可能已见但配对未见；这是组合泛化，不能简单叫“全新元素外推”。随机按行 CV 会让同一 (A,B) 的不同 X 泄漏。低 V 的验证样本仅 41 行，条件 tau 容易波动；低端误差、预算曲线和不确定性应配合使用。

全空间很小，枚举代理分数是计算上可行的校验。因此不能靠这个实例声称量子加速，也不能把读取被隐藏 DFT 真值当作枚举校验。材料发现的瓶颈可能在代理能否泛化，而不是有限表格最小值是否能算出。
