# P3 可复用的离线接口

以下是交接给后续设计者的资产。P2 的统计结论、能量阈值与矩阵哈希仅对 P2 实例生效。当前工作只完成接口盘点。

| 资产与入口 | 输入与输出契约 | 迁移时重新验证 |
|---|---|---|
| `validation_checker.py` 与 `validation_checker.diff` | 读整数 J、链边界、公共参考位、分组候选映射、原值与 q。检查合法态能量；动态规划给出最小非法代价；输出 G1/G2 及反例或缺失状态 | 每片以实际允许字典大小替换 529；检查片内覆盖、参考一致、跨片不漏不重、合法映射与 X 名称。零业务负对照必须保留 |
| `../../evidence/p2/verify.py` 与 `build_evidence.py` | 一次克隆的最小读取目录：矩阵、字典、块、终态原字节、回执、哈希；固定底层矩阵能量符号与参考规范 | 文本日期、原表和最优身份全部重新冻结。动态规划仅在矩阵拓扑满足定义时适用。重新证明非法界与错误聚合界，196/340 禁止搬用 |
| `hardware_data.py` 与 `../../figures/P2/data/columns.md` | 保留 task→return→chain 三层主键，能量选解、全返回集、局部 q 并列最优、只读时间事件均可追溯 | 添加片／组／轮次标识；轮次缺一片的分母在设计期冻结。跨片用原代理单位，不能横比独立归零的局部 q 或整数能量 |
| `registration.json`、`slots.csv`、`sa_data.py` | 先冻 slots 和真实整数输入；固定种子块各自的前缀，按全部计划块聚合。报告块命中、无可行块、条件 regret 与按能量选一个的结果 | 新矩阵、种子、负对照、主要预算点、失败规则和计算预算须重登记。跨任务/跨硬件不得继承同算力假设 |
| `check_faults.py`、`fault_results.json`、`distribution_receipt.json` | 从临时副本注入缺项、重复、越界、异参考、坏字节；通过合法置换；用独立 clone 复核只读包 | 对新字典增加跨片重复、跨片遗漏、片号错误或错误原表映射测试；外发仅复制明确列入清单的无凭据文件 |

时间安排：P2 运行本地 SA 时可整理上述接口与图件数据契约；P2 待已计划槽和独立复算收口，再进入用户另行裁决的 P3 方案阶段。P2 优化不占任何 P3 优化额度。
