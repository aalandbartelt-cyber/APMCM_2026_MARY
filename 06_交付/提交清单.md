# APMCM 提交清单

## A 首页/目录/页数

- [ ] p1 = Summary（Team Number / Problem Chosen / Summary / Keywords）
- [ ] p2 = Contents
- [ ] 正文从 Contents 后开始
- [ ] 正文 ≤25 页
- [ ] 每页 header = Team # + Page x of y
- [ ] 无姓名/学校/指导教师/邮箱

## B 英文

- [ ] 正文无中文
- [ ] 图题/表题/图例/坐标轴无中文
- [ ] 无全角标点
- [ ] 术语统一
- [ ] Summary 350–450 words；每问 2–3 个数字
- [ ] Summary 每问有数字

## C 图表/公式

- [ ] 图/表/公式编号连续
- [ ] 正文引用一致
- [ ] 图题在图下、表题在表上
- [ ] 表不跨页；图题同页
- [ ] 灰度可辨
- [ ] 单位英文
- [ ] 图内最终字号 ≥8 pt（至少 7 pt）
- [ ] 正文没有纯图片页/大段空白

## D 参考文献/附录

- [ ] 引用顺序编号
- [ ] 无僵尸文献
- [ ] 附录有软件名 + 全部源代码
- [ ] 代码路径与支撑包一致
- [ ] 附录代码可运行/可编译
- [ ] 未复现部分如实说明

## E 提交件

- [ ] 论文名 = 题号+队号.pdf
- [ ] Control sheet 已签名、命名正确、单独提交
- [ ] 支撑材料（若交）= 题号+队号fj.zip/rar
- [ ] 支撑包无原始数据、无身份信息
- [ ] PDF 元数据干净
- [ ] 干净环境打开 PDF 一次

## F 写作/证据

- [ ] 每问有 Direct answer / 明确结论
- [ ] Summary 每问有方法+数字+边界
- [ ] 问题重述不是抄题；至少一个歧义处理
- [ ] 每条关键假设有依据/范围/失效影响
- [ ] 每问有基线/验证/敏感性或失败案例
- [ ] 数字在 summary/正文/表/图/CSV 一致
- [ ] 绝对差/相对百分比/百分点没有混用

## G AI/诚信（条件性）

- [ ] 已查当届 APMCM/学校 AI 要求
- [ ] 没有把另一赛事 30%/50% 阈值或 AI 报告模板当 APMCM 规则
- [ ] 如要求披露：声明/References/标注/报告一致
- [ ] 所有 AI 辅助内容已人工核验
- [ ] 无编造引用/数据/结果
