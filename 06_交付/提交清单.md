# APMCM 提交清单

## A 首页/目录/页数

- [ ] p1 = Summary Sheet（Team Number / Problem Chosen / 2026 APMCM summary sheet / Summary / Keywords）
- [ ] p2 = Contents（目录，单独一页）
- [ ] 正文从 Contents 后开始，页码从 1 重新开始
- [ ] 正文 ≤25 页（Summary/Contents 不占 25 页；附录不限）
- [ ] 页眉只含队号+页码：p1/p2 只有 `Team # 队号`，正文起左队号 + 右 `Page x of y`
- [ ] `Page x of y` 的 y 由模板 LastPage 生成，没有手写 `of 25`
- [ ] 无姓名/学校/指导教师/邮箱
- [ ] 报名系统题号 = 论文题号 = 文件名首字母

## B 英文

- [ ] 正文无中文
- [ ] 图题/表题/图例/坐标轴无中文
- [ ] 无全角标点
- [ ] 术语统一
- [ ] Summary 350–450 words；每问 2–3 个数字
- [ ] Summary 每问有数字

## C 图表/公式

- [ ] 图/表/公式编号连续
- [ ] 正文引用一致
- [ ] 图题在图下、表题在表上
- [ ] 表不跨页；图题同页
- [ ] 灰度可辨
- [ ] 单位英文
- [ ] 图内最终字号 ≥8 pt（至少 7 pt）
- [ ] 正文没有纯图片页/大段空白

## D 参考文献/附录

- [ ] 正文方括号编号，按首次引用顺序
- [ ] 书籍条目带起止页码；期刊带卷号/页码；网络资源带访问日期
- [ ] 无僵尸文献
- [ ] 附录有软件名 + 全部源代码
- [ ] 源代码保留到获奖名单公布（组委会可能测试）
- [ ] 代码路径与支撑包一致
- [ ] 附录代码可运行/可编译
- [ ] 未复现部分如实说明

## E 提交件

- [ ] 论文名 = `#***.pdf`（题号+队号），例 `Aapmcm2630001.pdf`
- [ ] Control sheet = `#***cns.pdf` 或 `.jpg`，单独一页、三人签名、未混入论文
- [ ] 支撑材料仅在题面明确要求时提交；命名 `#***fj.rar/.zip`
- [ ] 如使用 AI：`Dapmcm26301618ai.pdf` 已生成并提交
- [ ] 支撑包无原始数据、无身份信息、无缓存/虚拟环境
- [ ] PDF 元数据干净
- [ ] 干净环境打开 PDF 一次
- [ ] 已提交到 https://www.saikr.com/vse/apmcm26 （论文+承诺书同时交）

## F 写作/证据

- [ ] 每问有 Direct answer / 明确结论
- [ ] Summary 每问有方法+数字+边界
- [ ] 问题重述不是抄题；至少一个歧义处理
- [ ] 每条关键假设有依据/范围/失效影响
- [ ] 每问有基线/验证/敏感性或失败案例
- [ ] 数字在 summary/正文/表/图/CSV 一致
- [ ] 绝对差/相对百分比/百分点没有混用

## G AI/诚信（2026 官方规定）

- [ ] 已判断是否使用 AI（LLM/生成式/代码助手/智能数学/数据分析/翻译/补全）
- [ ] 核心模型构建、算法设计与求解、结果分析由队员独立完成
- [ ] 使用 AI：正文相应位置有标注
- [ ] 使用 AI：References 有工具条目，格式 `[编号]工具名称，版本/型号，开发机构/公司，使用日期。`
- [ ] 使用 AI：已提交 `Dapmcm26301618ai.pdf`（工具/版本、用途/环节、提示词与回复、采纳与修改）
- [ ] 未使用 AI：References 后写官方原句 `本参赛队未使用任何AI工具`
- [ ] 没有把另一赛事 30%/50% 阈值或 AI 报告模板当 APMCM 规则
- [ ] 所有 AI 辅助内容已人工核验；无编造引用/数据/结果
- [ ] 不符合规定可能取消评奖资格
