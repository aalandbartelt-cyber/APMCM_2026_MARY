# docs/collab

跨角色协作文件。只写任务/结论/指针，不写密钥、隐私、未公开赛题原文。

## 文件

- `CURSOR_HANDOFF.md`：当前状态、下一步、不能动的东西。
- `decisions.md`：已拍板决策（题号、分工、交付口径）。
- `reviews/`：外部评审/评分报告；不改论文正文。

## 交接字段

```text
# HANDOFF
- 当前状态/版本/hash：
- 已完成：
- 未完成/下一步：
- 关键文件/路径：
- 不能动的东西：
- 验证命令/预期结果：
- 风险/待核：
```

## 角色

- Codex（WSL）：主环境/正式件。
- Cursor（WSL）：备份主力；`cursor/` 分支；不直接改 `main`/正式件。
- ZCode（Windows）：数据/文档/复核/提交检查。
- dsh/外部评审：只写 `docs/collab/reviews/`。

正式论文/正式图/交付包默认由主智能体写；其他角色需用户明确授权。
