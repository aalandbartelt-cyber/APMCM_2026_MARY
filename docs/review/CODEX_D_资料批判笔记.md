## 证据使用

本文件在系统阅读阶段增量记录。官方学习材料是平台使用的一手资料，但教程例子、营销性描述和侦察兵二次解读都需独立检查。文本提取可能损失公式上下标、表格对齐和图片，不能把提取后的公式无条件视为原始排版。最终状态与证据写入根目录复核报告。

## 官方学习地图：目前已经改变判断的内容

1. **演化图横轴与成本计时。** `4量子云服务使用指南.txt` 164–175 行明确说 T 是 Evolution Step/任意单位，单次相干演化 Tc 不包含排队、预处理、后处理和回传；优化任务可能有千次级演化。不能从截图横轴读端到端毫秒优势，也不能把文献的演化时间与自己 SA 的完整耗时相比。
2. **14bit 是受条件限制的服务，不是已持有权限。** 同文件 70–82 行：SPQC-X 需要超过 10 个标准任务、项目申请、单独配额，审核可能 3–5 个工作日且不承诺结果/返回时间。因此“为了攒数尽早投真机”不是由本题自动推出的行动，更不能覆盖用户的三闸/禁止擅自提交指令。
3. **PrecisionReducer 不等于原问题无损。** `1参数精度适配指南（8bit整数）.txt` 158–163、294 行说明截断+拆分的组合；所谓拆分无损只针对拆分前已截断/规整后的矩阵。需分别报告原始、截断、拆分后矩阵及恢复解的业务违反度。`only_feasible_solution` 的“可行”针对拆分变量一致性，不能代替原问题 one-hot/池成员资格检查。
4. **源数据规整化有条件。** 同文 231–279 行明确以小数部分不决定解区分为前提，使用“通常”而非定理。对本题低端 surrogate 分数，必须以候选差距及误差上界核查，不能因是预测数就随意取整。
5. **HOBO 原生 API 是一个合法选项。** `15处理降次问题教学.txt` 给出 HoboModel/reduce/verify_hobo_constraint；但原文没有规定 P3 必须使用它。侦察兵“官方期待路径”“手工联合编码应降级”的判断只是推测。自动降阶是否更合适要看辅助位、约束、精度与成本，不以 API 原生与否决定。
6. **罚系数工具不自动给紧界。** `10调整惩罚系数教学.txt` 表中 `get_min_penalty_for_equal_constraint` 写的是局部最优保证；“适配约束类型”不代表给出全局最小充分罚系数。教程的单比特变化/系数差解释需与源码及适用假设核对，不能照抄为全局证明。
7. **教程也有必须核查的代数表达。** `13处理约束问题教学.txt` 76–78 行为 `x1+x2>=x3` 给出 `P*x3*(1-x1-x2)`；取合法赋值 (1,1,1) 得 -P，并非合法域上恒为零的非负罚项。51 行对非负松弛变量的文字说明也与 `sum(a*x)-b+s=0` 的方向不符。后续仅使用可独立真值表核验的编码；不把教程汇编整体当作数学定理。
8. **官方文档自身包含版本混用。** 精度教程仍提 SimpleSolver，而 SDK 指南已说明 1.4.0 删除该类；示例中的 task_name_prefix 与当前安装 API 需逐项核对。阅读示例不等于已验证可运行。
9. **同一任务内的解池不是独立重复实验。** `5上手实训课程.txt` 110、142–144 行明确这一点。128 条返回解的可行率可以是解池描述，不能当作 128 次独立运行的成功概率，更不能直接用于 TTS 的重复成功公式。
10. **精确表格化不是“掉价的近似”。** `16组合优化论文解读.txt` 104–207 行的云柜员案例先枚举人数与等待时间映射，再用 one-hot 选择表格行；这与策展摘要中排斥表格化的口吻矛盾。有限域的函数近似误差和选择编码误差必须分开。
11. **混合分解与无证书预筛选不同。** 同文 258–285 行 Benders 有主子问题和割平面结构；它的存在不能给任意 top-k 元素预筛选提供保留全局最优的保证。QDOCK 669–678 行的加速表述明确含估计，不得改写成当前实例实测。
12. **Janus 证实可行性，不证实本题加速。** `17量子+AI论文解读.txt` 1247–1250 行明确量子生成分子评分与经典 SA 相当，结论是端到端概念验证。不能只引用该文前面的优势描述，省略此边界。
13. **一般采样不自动等于正确目标分布。** 同文 249–254 行的构象案例明确把重加权写为“暂未实现”；“路径质量接近”不能代替分布无偏性证明。对本题而言，CIM 返回低能样本也不能直接当作校准的材料通过概率。

## 侦察兵策展摘要中的待反证主张

- “黑箱 surrogate 无法精确嵌入 QUBO”“surrogate 必须比特二次”过强：有限完整池可以取表构建精确选择目标，表达能力与编码方式要分开讨论。此处先列为数学核对项，不运行 P2/P3。
- “纯 one-hot FM 在未见 (A,B) 下必死”过强：FM 的低秩嵌入会在已见元素/交互间共享参数，不能等同于每个未见对独立零信息的查表模型。是否有效只能由合法分组验证判断。
- “三个独立稀有条件”缺少独立性证据；带隙、VBM、CBM 很可能相关。应检查数据中的物理关系后再设计多输出模型或概率组合，不能直接相乘边际通过概率。
- “未用容忍因子是必需重做的硬伤”“按位价态明确”不应先验继承。X 是混合阴离子化学计量族，52×52 有许多非常规位点；价态、配位和有效阴离子半径的可识别性须优先核查。
- “O2S 永远不中”“N3 可以排除”等全网格结论不能成为训练选择规则；公告统计、已见标签和测试先验必须区分。
- “15/19 已由原论文破解”尚无此处的一手证据。当前只确认题面内部严格条件与平方铰链/README口径不一致，不检索原始隐藏 DFT 表来凑解释。

# Kaiwu SDK HTML 逐页核读增量

- 本地 HTML 不是正文纯文本，部分中文经历 Latin1/UTF8 错译。只读离线文件，用 BeautifulSoup 抽主 article/main、逐节点修复可逆乱码，保留代码和公式 TeX；缓存 `artifacts/codex_review/web_text/`。提取不自动标记已读。
- 1.4.4 changelog 的 `CIMOptimizer.interval` 单位为秒，旧版分钟值不能原样继承；constructor 文档用必传 `task_name`，同页版本历史又写曾采用 `task_name_prefix`，因此安装版本签名优先。没有为本次复核升级 SDK。
- `solve(..., sort_solutions=False)` 是所读 IsingSolver/CIM/SA 接口默认值。代码若把返回第 0 行当最优，需要核实旧安装版本的内部排序/显式参数，不能只凭教程示例推断。此处是待资产静态复核项，不宣称旧代码已经犯错。
- `SimulatedAnnealingSampler` 1.4.4 文档明确独立链、保留重复、返回最终态，**有限步退火不保证截止温度的平衡分布**；不能把任意返回样本直接称严格 Gibbs 样本。普通 Optimizer 解池与采样器也不是同一统计对象。
- preprocess API 的 `get_dynamic_range_metric` 定义是不同系数之间最大距离/最小正距离；精度教程却写 max|Xij|/min|Xij|（含 0），两者不一致，不复制教程公式作为本队定义。
- 精度教程的 Ising 展开将全体 i≠j 与 i<j 的系数混用；复制自旋平方展开把常数 `+2M` 写成 `−2M`（仅常数差，argmin 可能不受影响），但“项拆分”在其先前 `+Jij xi xj` 最小化约定下得到 `−Jij xi xj−|Jij|`，**耦合符号反向，不能由所给推导证明等价**。需要以开源实现、明确 SDK 的 `−sᵀJs` 约定、逐态能量验证为准，不因官方页面身份就接受错式。
- `PrecisionReducer` API 明确先截断再 split，若仍达不到位宽会再直接截断；其 `target_bits` 是新增变量预算控制，教程将之说成动态范围上限并不准确。`only_feasible_solution` 是拆分一致性，不会代替业务 one-hot/候选池检查。
- `get_min_penalty_for_equal_constraint` 仅保证从可行解单比特翻转的局部最优；不等于多个约束联合下的紧全局 λ。HOBO 降阶默认 penalty=1 也不是任意系数任务的安全证明。
- SDK 授权/首次 SA 初始化可能触发 license 请求；当前仅阅读接口，未调用授权、账户或任务入口。
