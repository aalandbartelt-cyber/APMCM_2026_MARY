# 01 参考学习

放 APMCM 往年优秀论文、题型分析、方法参考和外部评审材料。

- 本目录默认 **整目录 gitignore**，只保留本 README；不要把参考 PDF/图片/压缩包提交到公开仓库。
- 参考材料只用于结构/验证/表达，不照抄模型、数字、图或段落。
- 引用外部论文/数据时记录来源、版本和用途；不要伪造引用。

## 建议子目录（本地）

```text
优秀论文/            APMCM 2022—2025 优秀论文
题型分析/            A—D 题风格、数据规模、常见方法
方法参考/            优化/预测/评价/仿真/数据清洗
外部评审/            dsh/老师/往届选手意见
```

## 使用原则

- 先提炼“可迁移结构/证据链”，再决定是否借用方法。
- 不把往年题目的具体模型/结论套到 2026 题。
- 参考论文里的阈值/百分比不能自动成为今年标准；需要回源核验。
- 图/表只借组织方式，不复制数据或版式细节。
