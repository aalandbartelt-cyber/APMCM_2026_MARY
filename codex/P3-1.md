设不交叠批次 \(B_j\) 的并集为申报域 \(D\)。若每批返回原表最小点 \(c_j\)，则
\[
\min_{c\in D}\widehat V(c)=\min_j\widehat V(c_j).
\]
实现时由解码 ID 回查同一份冻结 `float64` 表，以 \((\widehat V,\mathrm{ID})\) 决胜。每批塑形都可能产生 \(q=0\)，跨批比较 \(q\)、整数能量或残差均无效。硬件只返回近优时，报告聚合候选对申报域精确枚举最优的 regret。任一切片缺失，该轮记为**覆盖不完整**，保留已取得的切片结果。

## 3. 三类常规编码与短链对照｜离线实算

统一合同为对称、零对角整数矩阵，\(|J_{ij}|\le127\)，能量 \(E(s)=-s^\top Js\)。常规编码使用原表减去允许集最小值，跨度记为 \(R\)，禁选格填 \(R\)，one-hot 罚取 \(1.1R\)。按最大绝对系数缩放至 127，再作最近偶数取整。允许候选仍逐项检查官方 mask。

- **263 位共享 Rosenberg**。使用 \(52+52+3\) 个原变量和 \(52\times3=156\) 个共享辅助位 \(y_{bx}=b_bz_x\)。业务项为 \(\sum C_{abx}a_a y_{bx}\)，乘积罚为 \(M(b_bz_x-2b_by_{bx}-2z_xy_{bx}+3y_{bx})\)。取 \(M=1.1\max_{bx}\sum_a|C_{abx}|\)，08 和 12 实算分别为 **2082.291116、3052.866237**。该界覆盖任意 A 位串上错误设置一个共享位可能获得的全部收益。
- **208 位联合双 one-hot**。使用 A 的 52 类与 **(B,X) 的 156 类**。若联合的是 (A,B)，该寄存器本身就有 2,704 类。208 的计数只适用于前一种构造。
- **三个 104 位问题**。固定 X，各自构造 52+52 位精确二元表，再以原始预测聚合三个解。三个 105 自旋矩阵分别计费、分别量化。
- **联合候选短链**。直接编码允许候选字典，详见第 4 节。本轮对照不纳入有损的 pairwise 投影。

下表的边数只数整数矩阵上三角非零项，包含参考位耦合。层数是**允许候选的不同整数能量数**。最坏 regret 穷尽了允许最低能量层的全部并列候选，并回查原表。G1 另查非法态，因此“允许最低”不会被误报为“全局基态”。

## 4. 短链分批、逐矩阵证书与退化检验

**摸底前声明的分组规则。** 12 按 X 各一批。08 按 X 各五批，各为 541、541、541、541、540 个候选。批内按冻结 A/B 轴的行主序，只保留允许 ID，再连续等分。对每批大小 \(N\)，在每组至少三候选且矩阵不超过 550 自旋的整数中，取使 \(G+3N/G\) 最小的 \(G\)，同值取较小者。这是显式赋予平均组长三倍权重的工程选择。18 批实算均得 40 组。每个盲批有 9 组各 14 个候选、31 组各 13 个候选，对应每链 13 或 12 个自由自旋。

**塑形和解码。** 逐批计算 \(r=\widehat V-\min_B\widehat V\) 与 \(R_B=\max_B r\)。本实例各批 \(R_B>2\)。在 \([0,2]\) 线性使用 0 至 0.75，在 \([2,R_B]\) 线性使用 0.75 至 1，乘 63 后取最近偶数得到 \(q\)。若 \(0<R_B\le2\) 则用 \(r/R_B\)，常数表令 \(q=0\)。组内相邻自旋耦合为 64，共享参考边由相邻 \(q\) 差分和两端边界项计算。每组全部合法态满足 \(E_g(t)=K_g+4q(t)\)。批内沿用固定的 \((q,\text{行主序索引})\) 解码，批间只用原始 \(\widehat V\)。

**证书定义。** G1 要求全部整数基态均合法。G2 要求所有整数基态经固定规则解码后的最坏原表 regret 不超过 0.1，同时另报是否精确等于零。本轮对每条短链既做矩阵动态规划，也穷举了全部自旋串。固定共享参考位后，各链独立，局部合法基态能量可相加。另求出产生非法输出或合法错选所需的最小残差。下表的残差界均由本批矩阵重算。

## 5. Kaiwu 求解与 11+2 配额｜拟预登记

批准后的顺序为**封存输入与实现 → 独立复算证书 → Git 锚定 → 本地 SA 与云端先导 → 两轮正式验证**。每张输入同时锚定矩阵、候选字典、链映射、解码器及检查器。数值哈希统一使用小端 `int64`、行主序矩阵字节。当前三个盲批的 SHA‑256 前 16 位依 O₃、NO₂、FO₂ 分别为 `beb1d7e6715c5420`、`f72fbc9e425ebc1f`、`3502da271cd352e7`。封存时保存完整摘要，并另记容器文件哈希。

**本地对照。** 以精确枚举作首要基线。用 Kaiwu SDK 1.4.4 的 `SimulatedAnnealingOptimizer` 对三张盲矩阵各做两块、每块 100 次重启，共 600 次。固定 \(\alpha=0.99\)，初温为矩阵最大绝对行和的四倍，终温为初温的 \(10^{-4}\)，每温度步迭代数取实际自旋数。种子固定为 \(300000+1000j+100b+i\)，其中切片 \(j=0,1,2\)，块 \(b=0,1\)，重启 \(i=0,\ldots,99\)。各块取严格合法的最低能量输出。成本按重启块与服务任务分别列示。

## 7. 批准后的验收门

1. **输入一致。** 四池输入哈希与冻结清单吻合，08/12 的 ID、mask、成员资格和逐位预测通过，拟合总账为 979。
2. **构造可复算。** 用 Kaiwu SDK 1.4.4 的 QUBO/Ising 转换与独立能量计算交叉核对。检查器独立读取导出的最终整数矩阵，验证每个允许 ID 恰好一次、参考位一致、跨组无意外边、G1/G2 及并列层最坏 regret。
3. **反例能被抓住。** 故意漏一个候选、重复一个 ID、改变一条参考边、混入禁选状态、交换跨批 \(q\) 比较器，五类测试必须分别报错。NO₂ 同时通过 P2 字典、矩阵、整数基态和解码结果的回归测试。
4. **先封存，后求解。** 将三矩阵完整哈希、字典、证书、检查器版本、SA 种子、槽位与停止规则写入不可覆盖回执并做 Git 锚定。后续入口只接受该锚。离线摸底实数、正式服务观测、失败与未完成槽分别归档，供逐项复核。
