## 2. 切分算法逆向重建（完全破解，可写入论文数据审计节）

公开发表的种子算法经重建验证为三层结构：

```
L1: 2704 个 (A,B) 对按 sha256("2026|<A>|<B>") 升序
    → 最小 510 对填入 holdout（"补足位"）
L2: 19 个正例宿主对被强制锁入 holdout
    → 510 + 19 = 529 ✓（与文件归属完全一致，510/510 全命中）
L3: 剩余 2175 对按 sha256("2027|<A>|<B>") 升序
    → 最小 567 对 = val（567/567 全命中），其余 1608 = train
```

**19 个正例宿主对**（纯公开信息可推导）：Ag-Nb, Au-Hf, Ba-Ga, Ba-In, Ba-Sn, Ba-Ta, Ca-Ge, Ca-Nb, Ca-Sn, Cs-Nb, In-Hf, La-Ti, Pb-Ga, Rb-Ti, Sr-Ga, Sr-Sn, Sr-Ta, Y-Pb, Y-Ta

### 2.1 伦理与纪律裁决（重要）

该推导完全基于公开信息（README 公开种子+文件归属），技术上不构成作弊。
但**用它缩小 Q2/Q3 候选空间属于利用切分设计元信息，违背题目设计意图**——本题的核心考核就是"在无法查表时靠代理模型排序"。

**裁决**：
1. 此发现作为**数据审计严谨性的证据**写入论文（极少有队伍能逆向出完整算法）；
2. 显式声明：**建模流水线不使用该信息**——surrogate 训练与 QUBO 求解仅使用 train/val 的物理标签；
3. 流水线冻结前不做任何"是否命中锁定对"的检查，防止间接泄漏迭代；
4. 冻结后可作为一次性事后自审计（写不写进论文届时再定，若写需注明是 post-hoc single-shot check）。

## 3. 口径锁定（题面矛盾的官方处理）

### 3.1 "15 vs 19"矛盾
- 题面一处称 "only 15 materials satisfy all conditions"，README 称 V=0 恰 19 条；
- **溯源**（Castelli et al. 2012, Energy Environ. Sci.）：原文献严格不等式口径（1.4 < gap < 3.1 等）候选为 15；
- **本题裁决口径**：以 README 的 V 定义为准——V=0 ⇔ 满足全部四条件，边界 inclusive（`max(0,dev)` 在 dev=0 处为零）；正例数 = **19**，正例率 = 19/18928 = **0.001004**；
- 论文数据节必须显式说明该口径选择及其与题面 15 的关系（评委可验证的严谨性展示）。

### 3.2 目标量 V 精确定义
`V = Σ v_i`，`v_i = [max(0, dev_i/0.5)]²`：

| 项 | 条件 | dev |
|---|---|---|
| v_form | e_form < 0.21 | e_form − 0.21 |
| v_gap_low | gap ≥ 1.4 | 1.4 − gap |
| v_gap_high | gap ≤ 3.1 | gap − 3.1 |
| v_vbm | VBM > 5.73 | 5.73 − VBM |
| v_cbm | CBM < 4.50 | CBM − 4.50 |

注意条件全部为**硬物理约束**，V 是其平方违反度（ hinge-quadratic ）。V=0 当且仅当全部满足。

### 3.3 gap=0 语义
gap=0 = 金属性（无带隙），**不是缺失值**；其 v_gap_low = (1.4/0.5)² = 7.84 的固定贡献——金属行天生携带 7.84 惩罚底数，这解释了 V 中位数 22.23 的高位分布。特征工程中 gap 作为输入特征时 0 是合法值。
