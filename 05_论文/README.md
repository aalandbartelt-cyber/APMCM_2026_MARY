# 05 论文

- `待审/`：候选稿、图源、编译脚本；所有角色可写，但文件命名带日期/负责人。
- `正式/`：正式论文 PDF/源文件；默认只由主智能体或用户授权角色写。

写作/图表规则：

```text
02_口径与约定/写作与审稿规范.md
02_口径与约定/图表规范.md
~/.codex/skills/mary-modeling-contest-pipeline-apmcm/references/09—22
```

## 命名建议

```text
待审/APMCM2026_<problem>_paper_YYYYMMDD.<ext>
待审/APMCM2026_<problem>_figs_YYYYMMDD/
正式/APMCM2026_<problem>_paper_final.<ext>
```

不要把旧版本覆盖掉；保留可回滚版本。
