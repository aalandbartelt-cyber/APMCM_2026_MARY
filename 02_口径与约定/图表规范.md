# APMCM 图表规范

> 本文件是项目级口径；深度规则见 skill `references/10_图表与排版项目规范.md`、`references/05_图表公式与LaTeX模板.md`。
> 总原则：按最终印刷尺寸检查可读性；图内全英文；图表支持结论，不做装饰。

## 1. 图的最终尺寸

- 图内文字目标 ≥8 pt，至少不低于 7 pt；缩到版心仍可读。
- 坐标轴、刻度、图例、面板字母、单位、注释都按最终尺寸检查。
- 多面板先定每格宽度，再定字号；不要画大再整体缩。
- 图题在图下，表题在表上；图与图题同页。
- 图内不得出现中文/中文截图。

## 2. 图的内容

- 每张图先写“回答什么问题/数据来源/读者先看到什么/结论句”。
- 同类结论不要用多张同构图重复；保留信息量最大的图，其余附录。
- 有不确定性的比较优先画区间/误差棒，不只画均值柱。
- 双轴图必须标两轴单位并说明为什么共轴。
- 颜色服务语义；灰度可辨；不要用红绿唯一编码。
- 图例要能独立读懂：变量、颜色/形状、单位、样本量/条件。
- 局部放大保留原坐标/比例说明。

## 3. 技术路线图/仿真图

- 技术路线图只放一张总览，回答“各问如何衔接”；模块写输入→输出→下一问用途。
- 技术路线图不要打断正文段落；图中文字 ≥8 pt。
- 三维图注明 kinematic simulation / visualization，不是真实机器人实验。
- 区分运动学回放时间与调度事件时钟；不要用慢放暗示实时性能。
- 视频放支撑材料时，论文里有清单和用途说明。

## 4. 表格

- 三线表；表题在表上；英文表头；单位写清。
- 数字按小数点/有效位对齐；百分比与小数口径统一。
- 表不跨页；跨页表重复表头；关键列在正文，完整表在附录。
- 每张表在正文被引用，并解释“比较了什么/结论是什么”。

## 5. 图文连续/页数

- 正文 ≤25 页；优先压缩重复叙述，不缩字号。
- 普通结果页避免整页只有图/大段留白；图与解释相邻。
- 核心结果表/图从附录回正文时，先确认页数仍合规。
- 不要用强制分页制造大片空白；最终逐页看底部留白。

## 6. PDF/Word 验收

- A4；正文 11/12 pt；页眉 `Team #... Page x of y`；p1 Summary、p2 Contents。
- 图/表编号连续；正文引用全部存在；无未定义引用。
- 图内无中文；文本层可检索；字体嵌入；无乱码/方块。
- Word：TOC 更新、分节符正确、图片不压缩、公式 OMML、导出 PDF 后逐页复核。
- PDF 元数据无姓名/学校/用户名。

## 7. 提交前

- [ ] 图/表编号连续、正文引用存在；
- [ ] 图内 ≥8 pt（至少 7 pt）；
- [ ] 图例/单位/坐标轴英文且可独立读懂；
- [ ] 灰度可辨；颜色不是唯一编码；
- [ ] 图表数字与 `key_numbers.csv` 一致；
- [ ] 正文没有纯图片页/大段空白；
- [ ] 核心结果在正文，完整表/过程图在附录；
- [ ] PDF 字体嵌入、文本可检索、元数据干净。
