# 00 赛题与规则

放置 APMCM 2026 官方规则、论文格式规范、LaTeX/Word 模板、control sheet 模板和正式赛题。

## 重要

- 官方发布/赛题原始数据放在 `官方发布/`，该目录已 gitignore，不进入公开仓库。
- 大文件/压缩包/参考 PDF 不要提交；只在 README 记录文件名、版本、获取日期。
- 队号/题号在报名后填入 `赛事参数.md`；不要把个人信息写进论文或公开仓库。
