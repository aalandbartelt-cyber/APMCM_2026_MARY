## 一、P3 悬案终审：X 族 = 恰好 3 个（O3/NO2/FO2），208-bit 口径正确

题面原文：

> **Problem 3: Choose One of Three + Two Degrees of Freedom**
> "Given 3 X candidates, namely **O3, NO2, and FO2**, select 1 of them, and at the same time select 1 from each of the 52 classes at the A site and the 52 classes at the B site, so that V̂(a, b, x) reaches its minimum."

**终审结论：**
- P3 联合编码 = 52(A) + 52×3(B×X 复合) = **208-bit，当前方案口径正确**；
- 416-bit（K=7）与正式题面**无关**，全文禁止出现；七族分解最多只能作为"超出题面的扩展讨论"且需明确标注；
- P2/P3 均为**单点选择**（minimize V̂ 的单一最优），不是 top-k 批量选择——one-hot 编码与此完全对齐。

## 二、四条件五罚项的精确表述（写作口径锁定）

题面原文：筛选条件是**四类**物理条件同时满足（formation energy、band-gap window、VBM、CBM），但 V 是**五项**平方罚之和——因为带隙窗口贡献上下两个罚项：

```
V = v_form + v_gap_low + v_gap_high + v_vbm + v_cbm
每项 v = [max(0, deviation / 0.5)]²

v_form:     e_form < 0.21   dev = e_form − 0.21
v_gap_low:  gap ≥ 1.4       dev = 1.4 − gap
v_gap_high: gap ≤ 3.1       dev = gap − 3.1
v_vbm:      VBM > 5.73      dev = 5.73 − VBM
v_cbm:      CBM < 4.50      dev = CBM − 4.50
```

论文措辞红线：**"four physical conditions, expressed as five squared penalty terms"**——不要说"five conditions"。

## 三、15/19 之谜的官方答案：边界包含语义

题面**自己并置了两个数字**：
- "only **15** materials in the complete dataset satisfy all of the conditions simultaneously"（严格不等式 e_form<0.21, 1.4<Eg<3.1, VBM>5.73, CBM<4.50）；
- "**19** records with V = 0 (prevalence 0.001004)"。

由于罚项形式 max(0,dev)² 在边界处（gap 恰好 1.4 等）罚为零，**V=0 实际对应非严格不等式**（≤/≥）；严格意义排除边界恰中的 4 条记录。**差异=边界语义，不是数据错误**。论文中按此口径一句话说清，不再"保持未解"：
> "The strict reading yields 15 records, whereas the penalty formulation V=0 corresponds to the non-strict boundary-inclusive reading, yielding 19; we adopt the official V=0 definition throughout."

### 核验得出的结构性事实（此前全队未知）

1. **盲池 11/12 恰好 = 全池 07/08 与 holdout 04 的交集**——盲池就是"标签被主办方扣留、只能纯靠预测"的那部分候选；
2. **全池 07/08 含 2,175 个训练可见组合**（07 中 1,608+567）——P2/P3 按题面用 02+03 训练后，这些组合的**真实标签在训练中可见**，若对全池求解，最小值大概率落在"记忆"而非"预测"的组合上；
3. 因此 "(or)" 的选择不是无所谓的：
   - **全池（07/08）**：叙事完整（52×52 全域），但含记忆捷径，科学性弱；
   - **盲池（11/12）**：529/1,587 个候选全部位于 holdout——**是真实发现能力的唯一诚实考场，也必然是主办方核验 P2/P3 成绩的评分池**（因为只有在 04 里他们才有真值可对）。

### 由此锁定的实施纪律（已通知 Codex 的待办）

1. **两池都做**：全池做完整 QUBO 叙事（编码/精度/成本账本），盲池做头条结果——论文 headline 必须是盲池上的选择结果；
2. **V̂ 表对全池成员统一用代理预测值**，不得对训练可见组合替换为真实标签（防"隐性记忆"——这是诚信红线 R1 的延伸）；
3. 结果分析时分层报告：全池最优落在训练可见区 vs 盲池区——若全池最优恰是训练记忆组合，如实披露并用盲池结果作主证据；
4. 529 = 07∩04 与 1,587 = 3×529 的结构意味着盲池元素覆盖仍是 52×52 全域散布（非 23×23 子网格——已实证否定该猜测）。

## 五、题面强制要求清单（合规底线）

1. **"This problem requires the use of the Kaiwu SDK for modeling and solving"**——Kaiwu SDK 建模求解是强制的；
2. **"express V̂ in QUBO form, complete the solution under the hardware coefficient constraints of SPQC, quantitatively analyze the solution results, and explain their cost item by item"**——**成本逐项解释（cost ledger）是题面明文要求**，不是自选加分项；
3. **价值框架题面自带**："Exhaustive enumeration does yield the answer, but it cannot demonstrate the engineering value at the level of 'which strategy reduces the computational effort and how rare targets are captured within a limited sampling budget.'"——论文价值叙事直接引用此框架：重点不是"能不能枚举"，而是"有限采样预算下的策略价值"；
4. Kaiwu Coding Skill 工具被题面点名允许辅助开发；
5. gap_gllbsc = 0 是金属性不是缺失值（题面明示，96.12%）——两阶段建模有题内依据；
6. A=B 组合"retained as in the original data and counted in the candidate space"——不得删除。
