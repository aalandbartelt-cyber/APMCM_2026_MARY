# Reproduce the figure plates

Run from this repository under WSL with the APMCM plotting template and licensed Times New Roman fonts available. The numerical plots read existing analysis outputs. The structural plate reads six archived VESTA exports. Source mappings and SHA-256 digests are in the pre-render specifications.

```bash
/usr/bin/python3 -B figures/P2/production/render.py
/usr/bin/python3 -B figures/P2/production/package.py
/usr/bin/python3 -B figures/P2/production/verify_content.py
```

A specific plate can be regenerated by passing its ID, e.g. `F3`. In F5(c) the two-dimensional ink silhouettes from the archived screenshots are transferred into the original coordinate ranges using original tick positions. A fixed 0.29 pt outline makes the traces readable in print. No time-series reconstruction is performed. The six untouched source screenshots are identified in the F5 specification and reproduced as a supplementary source comparison sheet in the audit directory.
