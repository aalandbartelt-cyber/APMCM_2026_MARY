## 2. 五项独立裁决

### D1：固定开发事件

令 eps=2，Y_eps=1[V<=2]，k=20。所有选模结果显式命名 `EF_{V<=2}@20`。02 共 11256 行、128 个近正例；03 共 3969 行、41 个近正例；均无 V=2 和 V=0。每个池报告 N、M、h、k，EF=(h/k)/(M/N)。M=0 时 EF/Recall 为 NA。

连续效用固定为 exp(-V/2)，用于辅助 NDCG@20；另报入选真实 V 最小值、中位数、均值、simple regret。k=1/5/10/50/100 仅为次预算。近正例事件不冒充隐藏 V=0。

理由：开发集无零正例，V=0 EF 未定义。证据：第三轮审定版第一项及官方 02/03 的独立计数。

### D2：回归与筛选分离

全部 gap=0 行保留。G=1[gap>0]；金属分支由题面有 V>=7.84。

H-soft：p=P(G=1|c)，u0=E[V-7.84|G=0,c]，u1=E[V|G=1,c]；

`Vhat_H=(1-p)*(7.84+max(0,u0))+p*max(0,u1)`。

筛选新增 `q=P(V<=2|G=1,c)` 与 `S_eps=p*q`。因 eps<7.84，乘积来自概率链式法则，无独立性假设。它不是 P(V=0)。门控及条件事件分类不加类别平衡权重，全部所属分支样本参加训练。硬路由与仅非金属专家只作不增加拟合的诊断。

每个拟合域按 AB 做两折 OOF，训练单调 sigmoid 校准器，再完整重训基模型。校准器以未加权标签拟合；任何外部评估标签不得进入。校准器拟合数据上的指标称 apparent，不称独立验证。独立内层/外层记录 raw/calibrated Brier、log-loss、可靠性曲线、分折/分 X 偏差，再发布乘积预测；差的校准保留警告，不伪称可靠概率。

回归分支少于 20 行或 10 个 AB 使用分支均值；分类无双类时用 (n_positive+1)/(n+2) 平滑先验。完整候选都返回结果，不按门控、tau 或 X 删除。首轮不再增加连续效用训练器；exp(-E[V]/2) 不解释为 E[exp(-V/2)]。

理由：平方误差最优条件均值与预算命中概率是不同目标。证据：第三轮审定版两阶段分数章节、题面 V 定义。

### D3：取消 RMSE 一票否决

删除 `RMSE<=1.02*best_RMSE`。数值模型按 RMSE、MAE、复杂度、固定 ID 依次选；筛选按 EF、连续效用 NDCG、较低 simple regret、复杂度、固定 ID 依次选。

主嵌套验证在内层完成选型，外层评价选择流程，并保存全部候选配对结果。报告 MSE=pi0*MSE_G0+pi1*MSE_G1 的两项实际贡献，不凭样本比例推断误差主导者。

有 V 输出的候选展示 RMSE—EF Pareto 前沿；纯筛选器的 RMSE 为 NA，单列筛选与校准表现，不强行转成 V。没有官方唯一评分公式的依据，不把内部主终点称为官方评分。

### D4：八路线与干净排序对照

全部主路线使用 F3+E1：R-raw、R-log、W-log、H-soft、S-eps、B-eps、L-single、L-hash4。

- R-raw：V 平方损失；R-log：log1p(V) 平方损失，expm1 不自动等于条件均值。
- W-log：训练域 log1p(V) 按 0.2 分箱，五点 Gaussian sigma=1 平滑，计数下限 1，权重 min(10,sqrt(dmax/di)) 后均值归一化。
- B-eps：同事件加权二分类，正负权重 N/(2*n_class)，只用本训练域计数；按未加权 OOF 标签校准。
- L-single：当前拟合域全部训练行一个 Query；L-hash4：AB 哈希均衡四 Query，同 AB 七个 X 不拆分。
- 两条排序器均用二元 Y_eps、显式 label_gain=[0,1]、训练 truncation=23、评估位置 20；旧七档指数增益退出主菜单。
- 固定三个 Query 哈希种子。首个参加选模，其他两个仅在同外折评估稳定性，不挑最好种子。
- rank score 以训练得分均值/std 定标，再作 OOF sigmoid 事件校准；不要求 softplus 伪装 V 输出。
- 主终点为每折完整评估池 top-20，再汇总；拼接 OOF top-20 为独立尺度诊断，不混为同一预算试验。不得用全外层标签统一校准后回评。

LightGBM 3.3.5 源码 `src/metric/dcg_calculator.cpp` 的单 Query 上限为 10000，低于 02 的 11256。隔离构建该版本，仅将 kMaxPosition 改为 20000，保存源码/补丁/库哈希并与原安装在小数据上做一致性验收，不升级现有环境。不以抽样或拆 Query 冒充全池单 Query。

### D5：E1 与反向消融

A/B 分位增加 Ns/Np/Nd/Nf Valence & Unfilled、Pettifor、Martynov-Batsanov EN、Zunger_rs_plus_rp，不对 A/B 平均。

- 八轨道字段采用 matminer v0.9.3 Magpie 固定表及文件 SHA；52 元素均有值，采用原表中性原子定义，不以氧化态推算。
- Pettifor、MB 使用本地 mendeleev 1.3.0；MB 的 nvalence(simple) 定义单独记录，不与 Magpie 轨道计数混同。
- Zunger 来自原有同一表 Rs+Rp，单位未明时只保留源尺度，不混算 Shannon 几何。
- 真实零不是缺失。保留 source、is_missing、source_interpolation_unknown、is_source_imputed。LightGBM 原生 NaN，Ridge 的插补仅训练域拟合。
- 不采用 E2、猜定唯一 d 电子数、实际 DFT/弛豫结构输入。

F1 保留 A/B 原子属性、IE1-3、EA、EN、价电子、原子/共价/Zunger 半径，X 计量/one-hot、性质的 mean/std/min/max 和少量位点差异。X 为三阴离子计量而不是分子基团；O3/NO2/FO2/N2O/N3/O2S/FNO 形式电荷分别为 -6/-7/-5/-8/-9/-6/-6。

F2 枚举正氧化态与电荷平衡组合，聚合多价态/自旋几何。A CN12 严格通道，近似通道依次 CN8/CN6；B CN6；N3- 的 CN4 1.46 A 仅近似通道。无平衡/缺半径不删行。t=(rA+rX)/(sqrt(2)*(rB+rX))，mu=rB/rX。

F3 增加 Bartel tau=rX/rB-nA*(nA-(rA/rB)/log(rA/rB))，仅 rA/rB>1+1e-6 有效。不交换 A/B，不以 4.18 硬筛选。混合阴离子均值半径和形式电荷均标明工程假设。

固定 R-log 的 F0/F3/F3+E1 配对对照。最终数值与筛选模型各做去电子、去几何/半径、去 X 化学统计；按依赖关系连带删除交互/标志，保留 X 身份/计量基础编码。Zunger 属电子块。删除 X 统计会连带删除依赖该统计的几何项，因此不作互斥因果归因。消融不重调参、不触发新搜索。

## 3. 验证、冻结与预算

02 拟合、03 最多三个候选一次批量开发选择、04 最终推断。03 不参与 P1 的任何学习型预处理/权重/校准。03 是既往使用过的开发集。

- 主验证：有向 AB 五外折、三内折。
- 元素阻断：52 元素哈希均衡五块，两位点都排除留出元素。
- X 留出：7 X * 5 AB 外折，训练同时排除该 X 和测试 AB。
- 目标区域：V<0.5/1/2 所在 AB 全留出，再补背景 AB 至约 20%。测试组的全部七 X 参加评价。
- 压力测试固定 R-log 与 S-eps；不同协议分别报告。

统一保守容量：15 leaves、min_child_samples=40、400 轮、learning_rate=.03、L2=1、4 线程、无行列随机采样；条件小样本头 7 leaves/min_child=10。取消两档容量搜索，不沿用旧 03 的 529 轮，不使用外层早停。

训练均值、A/B/X one-hot 加性 Ridge(alpha=1) 和均匀无放回随机对照保留。F0/F3 特征对照、额外种子和压力测试均是诊断，不参加额外自适应选型。
