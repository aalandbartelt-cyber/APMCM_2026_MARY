## A. 晶体结构渲染图（跨 P2/P3 共享，"真实材料"视觉锤）

| 项 | 内容 |
|---|---|
| 用途 | 最优候选材料的实体化呈现——"我们的解指向真实材料"，与实验文献核验互为表里 |
| 参考范式 | Wei et al. 2026 (Light: Sci. Appl. 15:74) Fig.6 分子对接图的角色对应物 |
| 数据源 | Materials Project mp-1222738（LaTiO2N, I2₁2₁2₁）；源文件已归档 figures/shared/crystal_structure/source/（CIF/POSCAR/超胞/MP json 四件） |
| 制作方法 | **VESTA 3.5.8 手动**（Windows，纯英文路径 D:\vesta_work\，⚠中文路径直接崩溃！）：打开 CIF → Edit→Bonds 删 La–O/La–N 键（La 变孤立球、不形成多面体）→ Style 切 Polyhedral → 用 2x2x1 超胞取景 → Export Raster Image Scale×3-4 + 勾透明背景 |
| caption 纪律 | 必须写 "Illustrative crystal structure ... adapted from Materials Project (mp-1222738)" 并引用数据库；绝不能写得像"我们算出了结构"；若候选为假设性材料须写 "idealized perovskite prototype" |
| 时机 | 依赖 P2 最终候选身份，**真机结果冻结后定稿**；若候选非 LaTiO2N 则查 MP/COD 同组成，无条目则建理想化立方原型（pymatgen 三行或 VESTA 手搭） |
| 交叉验证弹药 | MP 页面数据：Band Gap 1.31 eV（GGA 低估口径）、Formation Energy -2.972 eV/atom——供论文"外部数据库交叉核验"小节，注意只能事后核验不得反哺模型 |
| 状态 | **冻结（单视角基版）**——LaTiO2N_structure_mp1222738_frozen_v1.png 已过审归档（figures/shared/crystal_structure/）；终版图按下方"多视角合成方案"升级 |
| **多视角合成方案（用户定稿方向）** | 终版图=**三视角合成单图**：同一结构三个取向（建议 c 轴俯视 / a 轴侧视 / 斜向立体视角）排一排，视角间用**简洁弧形箭头**表达旋转关系—— crystallography 经典高级版面，一张图同时传达三维结构与取向信息。制作：VESTA 固定修正后设置（La 键已删），逐视角各导出一张 PNG（Scale 3-4+透明背景，**同一缩放比例与构图中心**）→ Python matplotlib/PIL 合成三 panel 一排，panel 间隙中央画弧形旋转箭头（FancyArrowPatch connectionstyle=arc3，灰黑色，简洁）→ 整图导出 600dpi。⚠三个视角必须用修正后的设置重导出——既有 1-4.png 含 La 多面体 bug，**仅作角度参考不可用**；⚠箭头只画旋转指示，不加文字解说（文字预算制）；⚠ panel 标注用 (a)(b)(c) 小标签即可 |

## B. 实例之眼：105-bit 耦合结构可视化（P2 正文候选）

| 项 | 内容 |
|---|---|
| 用途 | 让评委直观感到"这题真的上了量子硬件"；展示问题天然结构 |
| 参考范式 | Wei et al. Fig.3a/4a 圆形图布局（"毛线球"） |
| 制作方法 | Python+networkx：**分组环形布局**（A 位 52 个 one-hot 一组、B 位 52 个一组、辅助位），组间 W' 查表耦合与组内罚耦合分开设色/透明度；⚠禁止全连接直画（纯毛线球零信息）；备选主图=耦合矩阵热图+环形图降为同图 panel |
| 数据来源 | 冻结的 QUBO/Ising 矩阵 artifacts |
| 状态 | 预登记 |

## D. 分层达成率（P3 核心图，必出）

| 项 | 内容 |
|---|---|
| 用途 | GS/98%GS/95%GS 三档达成率——比单一命中率信息量高；且给结果叙事留弹性（材料筛选要的是好候选，不是数学基态） |
