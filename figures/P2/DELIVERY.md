## 印刷规格与返工记录

规格在第一张渲染前以 Git 提交 `ab05abc` 固定，逐图登记 54 个源文件哈希。另行复核了绘图清单中的 17 个文件。32 个单图成品组成 16 对 PDF/PNG。PNG 为 450 dpi，晶体为 600 dpi。成品图幅为 91–170 mm 宽，正文晶体图 169 × 91 mm。单图与审阅 PDF 的嵌入字体均为 Times New Roman，解析所得最小字号 8.5 pt。审阅 PDF 按单图原印刷尺寸嵌入，PDF 书签可跳页。

| 内部核验 | 发现与处理 |
|---|---|
| 3 秒首读 | 逐图用缩略图检查视线首先落到的证据，再与规格中的读图目标核对。逐张识别记录在 [自审表](audit/spec_out.csv)。此项为制作方内审。 |
| 彩色与灰度 | 逐图检查色版和 [灰度版](audit/grayscale/)。F1 补禁选纹理和星号；F3 的空心方块、实心圆与填纹对应两个口径；A1 拉开四种原子的明度后重新导出。 |
| 字体、图例与边界 | 修正 F1 左轴文字余量；F2 增加与原矩阵连接的前两链放大窗；F4 明示 95% 区间、分母与检验条件；A7 补负对照面板。通过 PDF 文字边界、嵌入字体和中日韩字符扫描。 |
| 晶体与设备 | 使用 VESTA 3.5.8 Linux 版重导六个原生场景。每个 Ti 周围为 4 O 与 2 N。晶体与平台图的 PDF 保留原生位图及矢量文字。晶体示例与生成外观图的证据边界写入图注。 |
| 原演化显示 | 从原蓝色线迹拷贝形状，按原始刻度重建轴和单位，刻度定位最大偏差小于一个源像素。六幅画面各保留原来的纵轴范围，全套原图可在[截图对照页](audit/A11_original_screenshots.pdf)放大比对。 |
| 数值与封存 | [独立复核](audit/content_verification.json)从历史表格复核两种裕度、逐格链计数和 SA 预算分母。旧封存清单的 4,727、543、150 项通过原有脚本。全程新增真机任务、模型拟合、SA 重启、论文修改和编译次数均为 0。 |
