## 2. 数学建模、精度处理与冻结选择

### 2.1 双 one-hot 及非矩形 mask

使用 \(a_i,b_j\in\{0,1\}\)，各 52 位：

\[
\sum_i a_i=1,\qquad \sum_j b_j=1.
\]

其中 \(a_i,b_j\) 分别表示 A/B 位选择。另以 \(M_{ij}\) 表示候选是否允许；业务可行必须同时满足两组 one-hot 和 \(M_{ij}=1\)。

令允许位置的预测为 \(W_{ij}\)，定义

\[
m=\min_{M_{ij}=1}W_{ij},\qquad
R=\max_{M_{ij}=1}W_{ij}-m,
\]

\[
C_{ij}=
\begin{cases}
W_{ij}-m,&M_{ij}=1,\\
R,&M_{ij}=0.
\end{cases}
\]

前提为允许集合非空、预测有限且 \(R>0\)。禁选位置的 \(R\) 是编码代价，不是材料预测。

若 \(R=0\)，允许候选全部并列最优；采用单位编码尺度、禁选代价 1、\(\lambda=1.1\)。该分支不参加 \(\lambda/R\) 扫描，所有涉及除以 R 的指标记不适用。

### 2.2 两编码、同一罚强度

原始编码：

\[
F_{\rm raw}=a^\top Cb+
\lambda\left[(\sum_i a_i-1)^2+(\sum_j b_j-1)^2\right].
\]

行列势固定先行后列：

\[
u_i=\min_jC_{ij},\quad
v_j=\min_i(C_{ij}-u_i),\quad
D_{ij}=C_{ij}-u_i-v_j,
\]

\[
F_{\rm rc}=a^\top Db+u^\top a+v^\top b+
\lambda\left[(\sum_i a_i-1)^2+(\sum_j b_j-1)^2\right].
\]

\(u,v,D\) 均非负，所有 one-hot 位置满足 \(D_{ij}+u_i+v_j=C_{ij}\)，包括禁选位置。

主比较统一固定

\[
\boxed{\lambda=1.1R}.
\]

**控制罚强度一致，评价表示本身；不声称评价各编码分别最优调参后的性能。** 放弃跨编码分别定标 λ。

### 2.3 λ 保证的边界

- **实数全局保证：**非负业务延拓存在允许零点，因此任意 \(\lambda>0\) 即排除 one-hot 非法全局最优；禁选 one-hot 的能量为 \(R>0\)。全局充分阈值的下确界为 0。
- **单比特下降保证：**\(\lambda>R\) 足以使 one-hot 非法态具有下降方向。更紧的局部充分界同时报告：
  \[
  \theta_{\rm raw}=\max\{\max_j\min_i C_{ij},\max_i\min_j C_{ij}\},
  \]
  \[
  \theta_{\rm rc}=\max\{\max_j\min_i(C_{ij}-v_j),
  \max_i\min_j(C_{ij}-u_i)\}.
  \]
- 这些结论不保证 CIM 动力学成功，不保证量化后保留下降方向，也不保证禁选 one-hot 具有单比特修复方向。

额外 \(\lambda/R=0.1,2.2\) 只用于离线敏感性，不改变正式设置。

### 2.4 裸线性罚证伪

考虑原始非负交叉表的裸线性形式

\[
L(a,b)=a^\top Cb+\alpha\sum_i a_i+\beta\sum_j b_j.
\]

假设某允许 one-hot 状态为全局最优，其业务值为 \(w\ge0\)。分别删除 A/B 激活位得 \(\alpha,\beta\le-w\)。再与两种“一组全选、另一组全零”比较：

\[
w+\alpha+\beta\le52\alpha,\qquad
w+\alpha+\beta\le52\beta,
\]

从而

\[
2w\le50\alpha+50\beta\le-100w.
\]

\(w>0\) 时矛盾；\(w=0\) 时只能 \(\alpha=\beta=0\)，非法全零态也并列最优。因此裸线性罚不能使全部全局最优严格业务可行。 \(\square\)

该证明不否定任意行列线性扩展或增广拉格朗日方法。线性罚分配零真机次数。依据：第五轮原始 PDF pp.2–3；Mirkarimi §2.2、§5、Appendix D。

### 2.5 SDK 与精度合同

安装版约定为

\[
H_J(s)=-s^\top Js,\qquad x_i=(1+s_i s_{\rm ref})/2.
\]

104 个业务二进制变量转换为 105 个 Ising 自旋。分别保存表平移、QUBO 常数和转换常数。

P2 比较：

- float64 原矩阵；
- N8：完整矩阵统一缩放，最近偶数取整至 \([-127,127]\)；
- M8：一次固定 mutate，再执行一次 N8。

\[
J_8=\operatorname{rint}\!\left(127J/\max|J|\right).
\]

不得分别缩放业务、罚项、场和耦合。离线位宽为 4、6、8、10、12、16。`get_min_penalty` 与解析界并列记录，不自动取最大值改变 λ；其返回值不当作精确全局阈值。

`var/item` 拆分及 `PrecisionReducer` 留待 P3。mutate 的输出及后续量化都必须接受实际矩阵审计，不能凭“保最优”名称免检。

### 2.7 Top-20 与确定性自动选择

原表排序固定为 `(float64 W, 既有 P1 组成 SHA-256)`；只有数值完全相等才进入排序 tie，不用显示小数或临时容差制造并列。

整数表排序固定为 `(精确 int64 能量, 同一组成 SHA-256)`。两个名单均先排除禁选组合；整数排序不能以原表 W 作次级键。

两表均输出第 20 位的严格前层、边界并列层、层内需选数量和全部候选键。除确定性名单外，报告整数边界不同取法下的 Top-20 保留范围。

记原表冻结名单为 \(T\)，整数严格前层为 \(L\)，边界层为 \(B\)，需从 B 中选 \(q=20-|L|\)，则：

\[
\mathrm{Ret}_{\min}=
\frac{|L\cap T|+\max(0,q-|B\setminus T|)}{20},
\]

\[
\mathrm{Ret}_{\max}=
\frac{|L\cap T|+\min(q,|B\cap T|)}{20}.
\]

选择采用保守的 \(\mathrm{Ret}_{\min}\)，确定性名单保留率仅作并列报告。原表自身的边界并列也完整披露。

唯一 CIM 候选为 11 池主 λ 下的 `raw-N8/raw-M8/rc-N8/rc-M8`。自动选择顺序：

1. 生成合同合格且双证明为 CERTIFIED；
2. **全部允许整数最优解**的最差原表 regret≤0.1；
3. 最差 regret 较小者优先；
4. \(\mathrm{Ret}_{\min}\) 较大者优先；
5. N8 优先 M8；
6. 固定配置 ID 字典序。

0.1 是沿用 P1 的**工程容差**，不是统计精度、预测可信区间或真实材料可行阈值。按每池实测 R 补报 \(0.1/R\) 及其百分数；不据 R 或结果改阈值。相对于 P1 开发 RMSE≈4.578，0.1 约为 2.18%，这个比例仅提供尺度背景，不构成准确性保证。

### 3.3 正式任务状态与分母

正式槽位固定 F01–F20，各最多发起一次提交。状态互斥：

| 状态 | 定义 |
|---|---|
| NOT_STARTED | 尚未调用提交接口 |
| SUBMISSION_FAILED | 已调用，确认未建立远程任务 |
| COMPUTATION_FAILED | 远程失败，或终态回包未通过预登记完整性检查 |
| PENDING | 已发起但截止时尚未完成，或是否受理仍待核实 |
| VALID_COMPLETED | 完整有效回包，身份、矩阵、样本及能量验证通过 |

提交结果不确定时先记 PENDING，查询原请求，禁止换名盲目重提。无可行解、低命中、高重复率均属于有效硬件结果，不得判为计算失败。

有效回包要求保留 100 次请求对应的原始结果或可核实的完整重数；无法解释的截断、格式损坏或缓存复用不得冒充有效重复任务。原始异常回包仍归档。

定义：

- \(N_A\)：已发起提交的槽位数，包含提交失败、计算失败和 pending；
- \(N_V\)：有效完成数；
- \(N_F\)：有效完成且至少有一个业务可行解的任务数；
- \(N_\epsilon\)：至少取得一个业务可行且 regret≤0.1 解的任务数。

分别报告：

| 指标 | 分子／分母 |
|---|---|
| 提交完成度 | \(N_A/20\) |
| 有效完成度 | \(N_V/20\) |
| 截止时端到端近优成功率 | \(N_\epsilon/N_A\) |
| 条件硬件近优成功率 | \(N_\epsilon/N_V\)，明确“条件于有效回包” |
| 全尝试可行任务率 | \(N_F/N_A\) |
| 计划槽位近优兑现率 | \(N_\epsilon/20\) |

分母为零时记 NA，并列出计数。未启动不是硬件失败；pending 是截止时未获得结果，不冒称最终计算失败。

### 3.4 无可行任务与 regret 主图

对有可行解的任务定义最好可行 regret：

\[
r_t=\min_{c\in\text{该任务可行返回}}W(c)-\min_{\text{允许候选}}W(c).
\]

无可行解时不编造有限 regret，也不通过 `nanmean` 静默删行。

主图采用

\[
G_{20}(x)=
\frac{\#\{t:\text{任务有可行解且 }r_t\le x\}}{20}.
\]

它直接显示“**取得可行解且 regret 不超过 x 的计划任务比例**”；失败、pending、未启动均保留在 20 槽位背景中。并列给出以 \(N_A\) 为分母的版本。

任务原始散点为主。条件 regret 分布另列，明确标题“条件于取得可行解”，标注 \(N_F/N_A\)；状态条展示没有数值点的任务。

### 3.5 小样本统计边界

- 先导不并入正式统计；任务内 100 样本不当作独立 Bernoulli。
- 20 正式槽位按序分四块登记，各五个；这不自动消除平台漂移。
- 二项区间采用 95% Clopper–Pearson，仅在明确假设“任务近似独立、同一成功概率、截止机制可接受”下作为辅助。不能解释为跨实例性能区间。
- 对计划兑现率优先报告完整计数，不把未启动槽位当随机硬件试验强行加二项区间。
- 5,000 次任务 bootstrap 降为辅助描述；重采样保留完整任务状态，条件 regret 每次重新形成有效子集。空子集次数必须公开。
- 全零／全一时明确 bootstrap 退化；二项区间不报零宽。例如 n=20 时，全零的双侧 95% 上界约 16.84%，全一的下界约 83.16%。
- 不作“CIM 显著优于 SA”的确认性结论，不从逐样本成功率推算独立采样 TTS。

依据：第七轮审查 pp.6–8。

## 4. 双证明、独立检查器与结论边界

### 4.1 证明 A：全部 one-hot 状态

**整数禁选状态与允许最优并列，也不能通过证书。** 哈希恰好选中允许候选不构成排除证明。

### 4.2 证明 B：排除非法态

固定参考自旋，将实际整数矩阵展开为二进制多项式。在每个基数类 \((r,s)\) 下，把线性、两组内部、跨组系数分别取所需数量的最小值求和，连同常数构成有效下界。

检查除 \((1,1)\) 外的 2,808 个基数类。下界必须**严格高于**允许最优能量；下界不够高只表示尚未证明，不能直接判为反例。

后备 B&B 固定变量关联权重降序、索引打破并列，分支 0 后 1；最多 \(10^6\) 节点或 600 秒。保存可检查的分支覆盖、剪枝界、反例或未闭合前沿。

### 4.3 四种证书状态

| 状态 | 判定 |
|---|---|
| CERTIFIED | 完整排除所有业务非法最优及非法并列，独立检查通过 |
| COUNTEREXAMPLE | 有独立复算的非法见证，能量不高于允许最优 |
| UNKNOWN | 下界不足、预算耗尽、超时或必要证据缺失 |
| IMPLEMENTATION_ERROR | 哈希、映射、能量展开、证明文件或检查实现违反合同 |

超时必须公开为 UNKNOWN，不并入数学反例。regret>0.1 是单独的**表示质量门未通过**，不能混称证书反例。

### 4.4 独立证书检查器

检查器只读取实际整数矩阵、变量映射、mask 和证书；不调用建模器、SDK 转换器或其能量展开函数。

独立通过直接计算 \(H=-s^\top Js\) 的零点、单激活和双激活能量重建二进制多项式，再检查：

- 完整常数、线性项和双计数；
- 参考位不进入业务基数；
- 基数下界与严格整数比较；
- B&B 分区覆盖与每个剪枝理由；
- 反例状态、业务违规和实际整数能量。

检查器自身超时记 UNKNOWN；逻辑或文件不一致记 IMPLEMENTATION_ERROR。服务端如果再次变换矩阵，本地证书不能直接冒充服务端矩阵证书。

### 4.5 必测场景

采用 2×2、2×3、3×3 全状态枚举验证正表、零点、常数表、非矩形 mask、A=B、参考位 ±1、量化新并列和非法基态。

新增协议测试覆盖：

- 全失败、全 pending、部分未启动、全零命中、全一命中；
- 有效回包但无可行解；
- 重复服务器 ID、提交超时、迟到回包、回包截断；
- 第 20 位大并列层、原表边界并列、禁选整数最低值；
- 回执重复创建、矩阵哈希改变；
- 证书超时、伪造剪枝界、漏分支和错误反例。

### 4.6 修复、敏感性与三层误差

SA/CIM 共用最小 Hamming 距离修复器：在允许 one-hot 状态中选距离最小者，并列使用固定组成哈希；**不读取 W 挑修复结果**。原始和修复结果分别统计，修复时间全额计入。

成员情景使用

\[
r_b(c)=W_b(c)-\min_uW_b(u).
\]

报告 rank、Top-5/20、p50/p90/p95/max、worst-regret，以及最大两个成员 regret 的均值，即上尾 CVaR\(_{0.9}\)。这些情景不替换正式均值目标；最小化中的下分位数是乐观情景。

三层分账：代理误差背景及成员分散度；表示造成的重排／并列／决策损失；对实际整数目标的搜索损失。mutate 非仿射改写单列。三层不作方差相加。

### 4.7 正文结论可识别性表

| 对象 | 可验证结论 | 不等价于 |
|---|---|---|
| 冻结代理表 | 枚举得到允许域最优／近优 | 真实材料 V 最优 |
