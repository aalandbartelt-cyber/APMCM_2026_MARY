# 03 求解

选题后按题目建子目录，例如：

```text
03_求解/
  A/ 或 B/ 或 C/ 或 D/
    data/        派生数据/中间表（原始数据不放这里）
    code/        本题代码入口
    results/     结果 CSV/JSON
    figures/     图源
    validation/  验证/敏感性/失败案例
    README.md    问题链、运行命令、结果对应
```

## 每问最小交付

- 问题链：输入 → 输出 → 下一问/业务动作；
- 数据清单：来源/版本/字段/单位/样本/缺失/处理；
- 模型：变量/目标/约束/假设/选择理由；
- 求解：算法/参数/种子/运行环境；
- 结果：指标/单位/分母/基线/比较；
- 验证：残差/敏感性/负对照/失败案例；
- README：运行命令、输入路径、输出路径、未测范围。

## 数字口径

- 所有关键数字从 `results/` 进论文；不要手抄。
- 建 `key_numbers.csv`：指标/单位/数据划分/分母/值/来源文件。
- 摘要/正文/表/图引用同一版本。
