## 使用原则

- 先提炼“可迁移结构/证据链”，再决定是否借用方法。
- 不把往年题目的具体模型/结论套到 2026 题。
- 参考论文里的阈值/百分比不能自动成为今年标准；需要回源核验。
- 图/表只借组织方式，不复制数据或版式细节。
